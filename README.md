# 11010tianyi.github.io

11010tianyi 的个人展示站（GitHub Pages），只列现在仍能打开的公开仓库。

## 页面

- `index.html` — 首页：精选作品（宇宙尺度之旅）+ 按分组的作品卡片
- `projects.html` — 项目页：同一批卡片，带分组筛选
- `404.html` — 自定义 404（使用绝对路径引用样式与页面，任意层级都能正常显示）
- `styles.css` — 两页共用样式

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

## 维护约定

- 只收录可实际打开的页面或仓库；上架前先验证链接返回 200。
- 首页与项目页的卡片内容保持同步：改一处，另一处也要改。
- 卡片标题优先用中文名，简介用仓库描述或 README 的原文。
